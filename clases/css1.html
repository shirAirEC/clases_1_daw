Bloque 1 — Fundamentos de CSS

Qué es CSS · Sintaxis · Selectores · Cascada · Especificidad · Unidades

Fundamentos

¿Qué es CSS?

CSS = Cascading Style Sheets
Lenguaje que describe cómo se presenta el contenido HTML.
  • HTML define qué hay en la página.
  • CSS define cómo se ve (colores, tamaños, posiciones, animaciones).
  • Creado por Håkon Wium Lie (1994).
  • Versión actual: CSS3, modular y en evolución.
HTML 
<h1>TechSummit 2026</h1>
<p>Conferencia de tecnología</p>
CSS 
h1 {
  color: #3b5bdb;
  font-size: 2rem;
}
p {
  color: #475569;
}
Fundamentos

La "Cascada"

El nombre completo es Cascading Style Sheets porque los estilos se aplican en cascada: con reglas de prioridad cuando dos declaraciones afectan al mismo elemento.

¿Qué estilo gana?

  1. El origen (navegador < autor < usuario)
  2. La especificidad del selector
  3. El orden en el código (si empatan, gana el último)
Dos reglas que compiten 
/* Regla 1 */
p { color: red; }

/* Regla 2 — gana porque va después */
p { color: blue; }
El párrafo se verá en azul: la segunda regla sobrescribe a la primera.

¿Dónde se escribe el CSS?

📄

Externo ⭐

Recomendado. Archivo .css separado.

<link rel="stylesheet"
  href="styles.css">
🏷️

Interno

Bloque <style> en el <head>.

<style>
  h1 { color: blue; }
</style>
⚠️

Inline

Evitar. Atributo style.

<h1 style="color:blue">
  Título
</h1>
En el ejercicio TechSummit usamos CSS interno (<style> en el <head>). En proyectos reales siempre archivo externo.

Fundamentos

Herencia

Algunas propiedades se heredan automáticamente de padres a hijos. Otras no.

Se heredan ✅

  • color, font-family, font-size
  • line-height, text-align
  • list-style, cursor

No se heredan ❌

  • margin, padding, border
  • background, width, height
  • display, position
Ejemplo con valores especiales 
body {
  font-family: 'Segoe UI', sans-serif;
  color: #1e293b;
  line-height: 1.7;
  /* Todos los elementos heredan */
}

/* Valores especiales */
.reset-color { color: initial; }
.like-parent { color: inherit; }
.neutral     { color: unset;   }
En TechSummit el body establece font-family y color. Todos los elementos los heredan.
Fundamentos

Especificidad

Cuando dos reglas apuntan al mismo elemento, gana la más específica. Se calcula con 3 niveles (A, B, C):

1,0,0
Estilos inline (style="")
0,1,0
IDs (#inscripcion)
0,0,1+
Clases, pseudoclases, atributos
0,0,1
Tipos (p), pseudoelementos
⚠️ !important supera todo. Úsalo solo como último recurso.
Comparativa 
/* Especificidad 0,0,1 */
p { color: black; }

/* Especificidad 0,1,0 — GANA */
.texto { color: blue; }

/* Especificidad 0,1,1 — MÁS GANA */
.contenido p { color: green; }

/* Especificidad 1,0,0 — MÁXIMO */
#titulo { color: red; }

/* !important — NUCLEAR */
p { color: pink !important; }
Fundamentos

Unidades CSS

Absolutas

  • px — píxeles (la más común en pantalla)
  • pt, cm, mm — para impresión

Relativas ⭐

  • em — del font-size del padre
  • rem — del font-size del html
  • % — porcentaje del padre
  • vw / vh — % del viewport
  • fr — fracción (solo en Grid)
TechSummit — combinación de unidades 
html { font-size: 16px; }

header {
  padding: 80px 20px;  /* px */
}

header h1 {
  /* clamp(min, preferido, max) */
  font-size: clamp(2.5rem, 6vw, 4rem);
}

main {
  max-width: 1000px;   /* px para max */
  margin: 0 auto;
  padding: 0 20px;
}

section {
  padding: 48px 40px;
  margin: 36px 0;
}

Bloque 2 — Modelo de caja

Margin · Padding · Border · Box-sizing · Position · Display

Box Model

El Modelo de Caja

margin (espacio exterior)
border (borde)
padding (relleno interior)
content
width × height
Ejemplo 
section {
  /* Contenido */
  width: auto;

  /* Relleno interior */
  padding: 48px 40px;

  /* Borde */
  border-radius: 12px;

  /* Espacio exterior */
  margin: 36px 0;

  /* Fondo */
  background: white;

  /* Sombra */
  box-shadow:
    0 4px 24px rgba(0,0,0,0.08);
}
Atajo: padding: arriba derecha abajo izquierda (sentido horario). Con 2 valores: vertical horizontal.
Box Model

box-sizing

❌ content-box (por defecto)

El width solo cuenta el contenido. Padding y border se suman.

div {
  width: 300px;
  padding: 20px;    /* +40px */
  border: 2px;      /* +4px  */
  /* Total: 344px 😱 */
}

✅ border-box (recomendado)

El width incluye padding y border. El elemento mide exactamente lo declarado.

* { box-sizing: border-box; }

div {
  width: 300px;
  padding: 20px;
  border: 2px;
  /* Total: 300px ✅ */
}
El reset * { box-sizing: border-box; } es la primera línea del CSS de TechSummit (y de casi cualquier proyecto moderno).

Box Model

Overflow — Desbordamiento

Controla qué ocurre cuando el contenido es más grande que su contenedor.

ValorComportamiento
visibleSe sale del contenedor (defecto)
hiddenSe recorta lo que sobresale
scrollSiempre muestra barras
auto ⭐Barra solo si es necesario
Ejemplos 
/* Texto largo en 1 línea */
.titulo-truncado {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis; /* "..." */
  max-width: 200px;
}

/* Tabla con scroll horizontal */
.tabla-responsive {
  overflow-x: auto;
}

/* Fondo que no se desborda */
header {
  overflow: hidden;
}
Box Model

Position

ValorDescripción
staticFlujo normal (defecto)
relativeDesplaza desde su posición. Crea contexto para absolute.
absoluteSale del flujo. Relativo al ancestro relative más cercano.
fixedRespecto al viewport. No se mueve al scrollear.
stickyRelative hasta un umbral, luego fixed.
top, right, bottom y left solo tienen efecto si position ≠ static.
Ejemplos 
/* Nav sticky — scrollea hasta 0,
   luego se queda fija */
nav {
  position: sticky;
  top: 0;
  z-index: 100;
}

/* Header con pseudoelemento absoluto */
header { position: relative; }
header::before {
  content: '';
  position: absolute;
  top: -50%; left: -50%;
  width: 200%; height: 200%;
}

/* Botón volver — fijo en pantalla */
.btn-volver {
  position: fixed;
  top: 20px;
  left: 20px;
}
Box Model

z-index y display

🃏 z-index — capas

Controla qué elemento queda por encima. Solo funciona con position ≠ static.

nav {
  position: sticky;
  top: 0;
  z-index: 100;
}
.btn-volver {
  position: fixed;
  z-index: 1000;
}

Bloque 3 — Layout

Flexbox y CSS Grid, los dos sistemas de maquetación modernos

Layout

Flexbox — Diseño en 1 dimensión

Flexbox organiza elementos en una fila o columna. Ideal para componentes: navbars, tarjetas, formularios.

Contenedor

  • display: flex
  • flex-direction: row | column
  • justify-content: eje principal
  • align-items: eje cruzado
  • flex-wrap: salto de línea
  • gap: espacio entre hijos

Hijos

  • flex-grow, flex-shrink, flex-basis, order
Ejemplos de TechSummit 
/* Nav */
nav ul {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  gap: 4px;
  list-style: none;
}

/* Footer links */
.footer-links {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  gap: 8px 24px;
}

/* Botones del formulario */
.form-actions {
  display: flex;
  gap: 16px;
}
Layout

Flexbox — Los dos ejes

justify-content — eje principal

  • flex-start / flex-end / center
  • space-between — extremos pegados
  • space-around — margen a los lados
  • space-evenly — reparto uniforme

align-items — eje cruzado

  • stretch (por defecto)
  • flex-start / flex-end / center
  • baseline — línea base del texto

Avanzado

Variables CSS (Custom Properties)

Permiten reutilizar valores y cambiar el tema de toda la web desde un solo punto.

Se declaran con --nombre en :root (o cualquier elemento) y se usan con var(--nombre).

Ventajas

  • Cambiar colores en un solo punto
  • Coherencia visual automática
  • Modificables con JavaScript
  • Heredables como cualquier propiedad
Variables del ejercicio TechSummit 
:root {
  --indigo: #1e1b4b;
  --indigo-light: #312e81;
  --violet: #7c3aed;
  --violet-soft: #a78bfa;
  --slate-50: #f8fafc;
  --slate-800: #1e293b;
  --radius: 12px;
  --shadow: 0 4px 24px
    rgba(0,0,0,0.08);
}

/* Uso de las variables */
section {
  background: white;
  border-radius: var(--radius);
  box-shadow: var(--shadow);
}

section h2 {
  color: var(--indigo);
  border-bottom: 3px solid
    var(--violet-soft);
}

Transiciones

Animan el cambio de un estado a otro (hover, focus, active…).

Sintaxis 
.elemento {
  transition:
    propiedad
    duración
    función-de-tiempo
    retardo;
}

/* Ejemplo */
nav a {
  transition: all 0.2s ease;
}

/* Múltiples propiedades */
.card {
  transition:
    transform 0.25s ease,
    box-shadow 0.25s ease;
}
TechSummit — hover de ponentes 
.speakers-grid article {
  transition:
    transform 0.25s,
    box-shadow 0.25s;
}
.speakers-grid article:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 40px
    rgba(0,0,0,0.12);
}

/* Nav link hover */
nav a:hover {
  background: var(--violet);
  color: white;
}

/* Botón submit */
button[type="submit"]:hover {
  transform: translateY(-1px);
}
⚠️ transition: all es cómodo pero puede afectar al rendimiento. Mejor especificar las propiedades exactas.

Animaciones con @keyframes

Sintaxis

  from {

  100% { transform: scale(1); }

Media Queries — Diseño Responsive

Aplican estilos solo cuando se cumplen ciertas condiciones (ancho, orientación…).

Mobile-first: diseña primero para móvil y añade estilos para pantallas grandes con min-width.
Mobile-first 
/* Base: móvil */
.speakers-grid {
  grid-template-columns: 1fr;
}

/* Tablet ≥ 640px */
@media (min-width: 640px) {
  .speakers-grid {
    grid-template-columns:
      repeat(2, 1fr);
  }
}

/* Desktop ≥ 1024px */
@media (min-width: 1024px) {
  .speakers-grid {
    grid-template-columns:
      repeat(3, 1fr);
  }
}
TechSummit — desktop-first 
@media (max-width: 640px) {
  section, aside {
    padding: 28px 20px;
    margin: 20px 0;
  }
  nav ul { gap: 2px; }
  nav a {
    font-size: 0.8rem;
    padding: 6px 10px;
  }
  dl {
    grid-template-columns: 1fr;
  }
  .form-actions {
    flex-direction: column;
  }
  .speakers-grid {
    grid-template-columns: 1fr;
  }
  thead th, tbody td {
    padding: 8px 10px;
    font-size: 0.82rem;
  }

Reset CSS moderno

Los navegadores aplican estilos por defecto distintos. Un reset unifica el punto de partida.

Reset mínimo (TechSummit)

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

html {
  scroll-behavior: smooth;
}

Reset completo moderno

*, *::before, *::after {
  box-sizing: border-box;
}
* { margin: 0; }

body {
  line-height: 1.5;
  -webkit-font-smoothing:
    antialiased;
}

img, video, svg {
  display: block;
  max-width: 100%;
}

input, button, textarea, select {
  font: inherit;
}

Pseudoelementos

Crean elementos visuales sin añadir HTML.

PseudoelementoInserta…
::beforeAntes del elemento
::afterDespués del elemento
::placeholderPlaceholder de input
::selectionTexto seleccionado
Ejemplo 
/* Efecto decorativo del header */
header::before {
  content: ''; /* obligatorio */
  position: absolute;
  top: -50%; left: -50%;
  width: 200%; height: 200%;
  background:
    radial-gradient(circle at 30% 70%,
      rgba(124,58,237,0.3), transparent),
    radial-gradient(circle at 70% 30%,
      rgba(245,158,11,0.15), transparent);
  pointer-events: none;
}

/* Indicador en FAQ */
summary::before {
  content: '+ ';
  color: #7c3aed;
  font-weight: 700;
}
details[open] summary::before {
  content: '− ';
}
El atributo content es obligatorio en ::before y ::after, aunque esté vacío (content: '';).
