🎨¿Qué es CSS?

CSS = Cascading Style Sheets
Lenguaje que describe cómo se presenta el contenido HTML.
  • HTML define qué hay en la página.
  • CSS define cómo se ve (colores, tamaños, posiciones, animaciones).
  • Creado por Håkon Wium Lie (1994).
  • Versión actual: CSS3 (modular, evoluciona continuamente).
<!-- HTML -->
<h1>TechSummit 2026</h1>
<p>Conferencia de tecnología</p>
/* CSS */
h1 {
  color: #264de4;
  font-size: 2rem;
}
p {
  color: #475569;
}
Analogía útil: HTML es el esqueleto, CSS es la ropa y el maquillaje. Vídeo referencia: 03:04 — "Qué es CSS".

🌊La "Cascada"

El nombre completo es Cascading Style Sheets porque los estilos se aplican en cascada: de arriba a abajo, con reglas de prioridad.

¿Qué determina qué estilo gana?

  1. El origen (navegador < autor < usuario)
  2. La especificidad del selector
  3. El orden en el código (el último gana si empatan)
/* Regla 1 */
p { color: red; }

/* Regla 2 — gana porque va después */
p { color: blue; }
El párrafo se verá en azul porque la segunda regla sobreescribe la primera.
Vídeo referencia: 06:43 — "El significado de Cascada".

📍¿Dónde se escribe el CSS?

📄

Externo

Archivo .css separado. Recomendado.

<link rel="stylesheet"
  href="styles.css">
🏷️

Interno

Bloque <style> en el <head>.

<style>
  h1 { color: blue; }
</style>
⚠️

Inline

Atributo style. Evitar.

<h1 style="color:blue">
  Título
</h1>
En el ejercicio TechSummit usamos CSS interno (<style> en el <head>). En proyectos reales siempre archivo externo.

🧬Herencia

Algunas propiedades CSS se heredan automáticamente de padres a hijos. Otras no.

Se heredan ✅

  • color, font-family, font-size
  • line-height, text-align
  • list-style, cursor

NO se heredan ❌

  • margin, padding, border
  • background, width, height
  • display, position
body {
  font-family: 'Segoe UI', sans-serif;
  /* Todos los elementos heredan
     este font-family */
  color: #1e293b;
  line-height: 1.7;
}

/* Valores especiales */
.reset-color {
  color: initial;   /* valor inicial */
}
.like-parent {
  color: inherit;   /* fuerza herencia */
}
.neutral {
  color: unset;     /* hereda o inicial */
}
En TechSummit el body establece font-family y color base. Todos los elementos los heredan.
Vídeo referencia: 32:35 — "Herencia" y 37:48 — valores especiales.

⚖️Especificidad

Cuando dos reglas apuntan al mismo elemento, gana la más específica. Se calcula con 3 columnas (A, B, C):

1,0,0
Estilos inline (style="")
0,1,0
IDs (#inscripcion)
0,0,1+
Clases (.card), pseudoclases (:hover), atributos
0,0,1
Tipos (p), pseudoelementos (::before)
!important supera todo. Úsalo solo como último recurso. 
/* Especificidad 0,0,1 */
p { color: black; }

/* Especificidad 0,1,0 — GANA */
.texto { color: blue; }

/* Especificidad 0,1,1 — MÁS GANA */
.contenido p { color: green; }

/* Especificidad 1,0,0 — MÁXIMO */
#titulo { color: red; }

/* !important — NUCLEAR */
p { color: pink !important; }
Vídeo referencia: 01:08:04 — "Especificidad". Herramienta útil: specificity.keegan.st

📏Unidades CSS

Absolutas

  • px — píxeles (la más común para pantalla)
  • pt, cm, mm — para impresión

Relativas ⭐ Preferir estas

  • em — relativa al font-size del padre
  • rem — relativa al font-size del html
  • % — porcentaje del elemento padre
  • vw — % del ancho del viewport
  • vh — % del alto del viewport
  • fr — fracción (solo en Grid)
/* TechSummit — combinación de unidades */
html { font-size: 16px; }

header {
  padding: 80px 20px;  /* px */
}

header h1 {
  /* clamp(min, preferido, max) */
  font-size: clamp(2.5rem, 6vw, 4rem);
}

main {
  max-width: 1000px;   /* px para max */
  margin: 0 auto;
  padding: 0 20px;
}

section {
  padding: 48px 40px;  /* px */
  margin: 36px 0;
}
Vídeo referencia: 01:18:37 — "Unidades relativas y absolutas". Regla práctica: usar rem para tamaños de texto, px para bordes y sombras, % para anchos fluidos. clamp() es moderno y muy útil para tipografía responsive.

📐box-sizing

❌ content-box (por defecto)

El width solo cuenta el contenido. Padding y border se suman → el elemento es más grande de lo esperado.

div {
  width: 300px;
  padding: 20px; /* +40px */
  border: 2px solid; /* +4px */
  /* Total real: 344px 😱 */
}
✅ border-box (recomendado)

El width incluye padding y border. El elemento siempre mide exactamente lo que declaras.

/* Reset universal */
* {
  box-sizing: border-box;
}

div {
  width: 300px;
  padding: 20px;
  border: 2px solid;
  /* Total real: 300px ✅ */
}
El reset * { box-sizing: border-box; } es la primera línea del CSS de TechSummit (y de casi cualquier proyecto moderno).
Vídeo referencia: 01:40:35 — "box-sizing".

🌊Overflow — Desbordamiento

Controla qué pasa cuando el contenido es más grande que su contenedor.

Valor Comportamiento
visible Se sale del contenedor (defecto)
hidden Se recorta lo que sobresale
scroll Siempre muestra barra de scroll
auto Barra solo si es necesario ✅ 
/* Texto largo en 1 línea */
.titulo-truncado {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis; /* "..." */
  max-width: 200px;
}

/* Tabla con scroll horizontal */
.tabla-responsive {
  overflow-x: auto;
}

/* Fondo que no se desborda */
header {
  overflow: hidden;
  /* Mantiene los efectos
     de radial-gradient dentro */
}

📌Position

Valor Descripción
static Flujo normal (defecto)
relative Desplaza desde su posición original. Crea contexto para hijos absolute.
absolute Sale del flujo. Se posiciona respecto al ancestro relative más cercano.
fixed Respecto al viewport. No se mueve al hacer scroll.
sticky Relative hasta un umbral, luego fixed.
top, right, bottom, left solo tienen efecto si position ≠ static. 
/* Nav sticky — scrollea hasta 0,
   luego se queda fija */
nav {
  position: sticky;
  top: 0;
  z-index: 100;
}

/* Header — pseudo-elemento absoluto */
header { position: relative; }
header::before {
  content: '';
  position: absolute;
  top: -50%; left: -50%;
  width: 200%; height: 200%;
  /* Efecto decorativo */
}

/* Botón volver — fijo en pantalla */
.btn-volver {
  position: fixed;
  top: 20px;
  left: 20px;
}

🃏z-index y display

z-index — capas

Controla qué elemento queda por encima. Solo funciona con position ≠ static.

nav {
  position: sticky;
  top: 0;
  z-index: 100; /* encima de todo */
}
.btn-volver {
  position: fixed;
  z-index: 1000; /* más arriba */
}

display — tipo de caja

Valor Comportamiento
block Ocupa toda la línea (div, p…)
inline Fluye en la línea (span, a…)
inline-block Inline pero acepta width/height
none Oculta el elemento (no ocupa espacio)
flex Activa Flexbox ✨
grid Activa Grid ✨

🏋️Flexbox — Diseño en 1 dimensión

Flexbox organiza elementos en una fila o columna. Ideal para componentes: navbars, tarjetas, formularios.

Propiedades del contenedor

  • display: flex — activa flexbox
  • flex-direction — row | column
  • justify-content — eje principal
  • align-items — eje cruzado
  • flex-wrap — salto de línea
  • gap — espacio entre elementos

Propiedades de los hijos

  • flex-grow — cuánto crece
  • flex-shrink — cuánto encoge
  • flex-basis — tamaño base
  • order — orden visual
/* Nav de TechSummit */
nav ul {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  gap: 4px;
  list-style: none;
}

/* Footer links */
.footer-links {
  display: flex;
  flex-wrap: wrap;
  justify-content: center;
  gap: 8px 24px;
}

/* Botones del formulario */
.form-actions {
  display: flex;
  gap: 16px;
}
Vídeo referencia: 02:27:34 — "Flexbox", 02:32:02 display:flex, 02:33:36 flex-direction, 02:55:59 justify-content.

↔️Flexbox — Los dos ejes

justify-content — eje principal

  • flex-start — al inicio
  • flex-end — al final
  • center — al centro
  • space-between — espaciado extremos
  • space-around — espaciado con margen
  • space-evenly — espaciado uniforme

align-items — eje cruzado

  • stretch — estira (defecto)
  • flex-start / flex-end
  • center — alineación vertical centrada
  • baseline — alinea la línea base del texto

🧩Variables CSS (Custom Properties)

Las variables CSS permiten reutilizar valores y cambiar el tema de toda la web desde un solo lugar.

Se declaran con --nombre-variable dentro de :root (o cualquier elemento) y se usan con var(--nombre).

Ventajas

  • Cambiar colores en un solo punto
  • Coherencia visual automática
  • Se pueden modificar con JavaScript
  • Heredables como cualquier propiedad
/* Variables del ejercicio TechSummit */
:root {
  --indigo: #1e1b4b;
  --indigo-light: #312e81;
  --violet: #7c3aed;
  --violet-soft: #a78bfa;
  --slate-50: #f8fafc;
  --slate-800: #1e293b;
  --amber-light: #fef3c7;
  --radius: 12px;
  --shadow: 0 4px 24px
    rgba(0,0,0,0.08);
}

/* Uso de las variables */
section {
  background: white;
  border-radius: var(--radius);
  box-shadow: var(--shadow);
}

section h2 {
  color: var(--indigo);
  border-bottom: 3px solid
    var(--violet-soft);
}
Las variables CSS son modernas y muy potentes. No son lo mismo que las variables de Sass/Less (que son compiladas). Estas son nativas del navegador y dinámicas.

🎬Transiciones

Las transiciones animan el cambio de un estado a otro (hover, focus, active…).

/* Sintaxis completa */
.elemento {
  transition:
    propiedad
    duración
    función-de-tiempo
    retardo;
}

/* Ejemplo */
nav a {
  transition: all 0.2s ease;
}

/* Atajo múltiples propiedades */
.card {
  transition:
    transform 0.25s ease,
    box-shadow 0.25s ease;
}
⚠️ transition: all es práctico pero puede afectar rendimiento. Mejor especificar las propiedades exactas. 
/* Ponentes — tarjeta hover */
.speakers-grid article {
  transition:
    transform 0.25s,
    box-shadow 0.25s;
}
.speakers-grid article:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 40px
    rgba(0,0,0,0.12);
}

/* Nav link hover */
nav a {
  transition: all 0.2s;
}
nav a:hover {
  background: var(--violet);
  color: white;
}

/* Botón submit */
button[type="submit"] {
  transition: all 0.2s;
}
button[type="submit"]:hover {
  background: var(--indigo-light);
  transform: translateY(-1px);
}

🎞️Animaciones con @keyframes

Las animaciones permiten transiciones entre múltiples estados sin necesidad de interacción del usuario.

/* 1. Definir la animación */
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(30px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* 2. Aplicarla */
.hero-content {
  animation: fadeInUp 0.8s ease;
}

/* Con múltiples estados */
@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.05); }
  100% { transform: scale(1); }
}

Propiedades de animation

Propiedad Valor
animation-name nombre del @keyframes
animation-duration 0.8s, 500ms
animation-iteration-count 1, infinite
animation-direction normal, reverse, alternate
animation-fill-mode forwards — mantiene estado final
animation Atajo de todas las anteriores 
/* Atajo */
.home-container {
  animation: fadeInUp 0.8s ease;
}

📱Media Queries — Diseño Responsive

Las media queries aplican estilos solo cuando se cumplen ciertas condiciones (ancho de pantalla, orientación, etc.).

Mobile-first: diseña primero para móvil y añade estilos para pantallas más grandes con min-width. 
/* Móvil: estilos base */
.speakers-grid {
  grid-template-columns: 1fr;
}

/* Tablet: desde 640px */
@media (min-width: 640px) {
  .speakers-grid {
    grid-template-columns:
      repeat(2, 1fr);
  }
}

/* Desktop: desde 1024px */
@media (min-width: 1024px) {
  .speakers-grid {
    grid-template-columns:
      repeat(3, 1fr);
  }
}

🔄Reset CSS y Normalize

Los navegadores tienen estilos por defecto distintos. El Reset CSS elimina esas diferencias para partir de cero.

Reset mínimo (TechSummit)

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

html {
  scroll-behavior: smooth;
}

Reset completo moderno

*, *::before, *::after {
  box-sizing: border-box;
}
* {
  margin: 0;
}
body {
  line-height: 1.5;
  -webkit-font-smoothing:
    antialiased;
}
img, video, svg {
  display: block;
  max-width: 100%;
}
input, button, textarea, select {
  font: inherit;
}
p, h1, h2, h3, h4 {
  overflow-wrap: break-word;
}
Vídeo referencia: 01:24:26 — "Reset CSS y Normalize". Normalize.css mantiene algunos estilos útiles del navegador; el reset los elimina todos.

🔮Pseudoelementos

Los pseudoelementos crean elementos visuales sin necesidad de HTML adicional.

Pseudoelemento Inserta…
::before Contenido antes del elemento
::after Contenido después del elemento
::placeholder Estilo del placeholder
::selection Texto seleccionado por el usuario 
/* Efecto decorativo del header */
header::before {
  content: ''; /* obligatorio */
  position: absolute;
  top: -50%; left: -50%;
  width: 200%; height: 200%;
  background:
    radial-gradient(circle at 30% 70%,
      rgba(124,58,237,0.3), transparent),
    radial-gradient(circle at 70% 30%,
      rgba(245,158,11,0.15), transparent);
  pointer-events: none;
}

/* Indicador en FAQ */
summary::before {
  content: '+ ';
  color: #7c3aed;
  font-weight: 700;
}
details[open] summary::before {
  content: '− ';
}
Los pseudoelementos ::before y ::after son muy potentes para decoración. El atributo content: '' es obligatorio aunque esté vacío.
