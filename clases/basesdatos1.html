🗄️¿Qué es una Base de Datos?

Base de Datos: Conjunto organizado de datos estructurados que se almacenan electrónicamente en un sistema informático.

❌ Sin Base de Datos

  • Archivos Excel dispersos
  • Documentos Word con listas
  • Datos duplicados
  • Difícil de mantener
  • No hay control de acceso

✅ Con Base de Datos

  • Datos centralizados
  • Sin duplicación
  • Fácil de actualizar
  • Múltiples usuarios
  • Seguridad y respaldos

🏗️El Modelo Relacional

Creado por Edgar F. Codd en 1970 en IBM

Organiza los datos en tablas (también llamadas relaciones)

Componentes principales:

📋 Tabla (Relación)

Conjunto de datos sobre un mismo tema

Ejemplo: Tabla cliente

📊 Columna (Atributo)

Característica o propiedad

Ejemplo: nombre, email

📝 Fila (Tupla/Registro)

Un dato concreto

Ejemplo: Juan Pérez, juan@email.com

🔑 Clave Primaria (PK)

Identifica de forma única cada fila

Ejemplo: cliente_id

📋Anatomía de una Tabla

Tabla: cliente

🔑 cliente_id nombre apellido email activo
1 Juan Pérez juan@email.com ✅
2 María García maria@email.com ✅
3 Carlos López carlos@email.com ❌

Columnas: nombre, apellido, email, activo

Filas: 3 clientes (Juan, María, Carlos)

Clave Primaria: cliente_id (único para cada cliente)

🔑Clave Primaria (Primary Key)

Clave Primaria: Campo que identifica de forma única e inequívoca cada fila de una tabla.

Características:

  • ✅ Única: No puede haber dos filas con el mismo valor
  • ✅ No nula: Siempre debe tener un valor
  • ✅ Inmutable: No debería cambiar nunca
  • ✅ Simple: Preferiblemente un número entero

Ejemplos:

cliente_id, pelicula_id, pedido_id

Normalmente se auto-incrementan: 1, 2, 3, 4...

🔗Clave Foránea (Foreign Key)

Clave Foránea: Campo en una tabla que hace referencia a la clave primaria de otra tabla.

Sirve para establecer relaciones entre tablas.

Tabla: cliente

🔑 cliente_id nombre
1Juan
2María

Tabla: alquiler

🔑 alquiler_id 🔗 cliente_id fecha
112024-01-15
222024-01-16
312024-01-20

El campo cliente_id en alquiler es una clave foránea que apunta a cliente

🤔 Pregunta para pensar:

Dada la tabla alquiler, ¿cuál es el nombre del cliente cuya fecha es 2024-01-20?

✅ Respuesta: Juan (cliente_id = 1 en el alquiler_id = 3)

🚀Tu Primera Consulta SQL

SELECT * FROM cliente;

¿Qué significa?

  • SELECT = "Selecciona" o "Muéstrame"
  • * = "Todas las columnas"
  • FROM cliente = "De la tabla cliente"
  • ; = Fin de la instrucción

Resultado: Muestra TODOS los datos de TODOS los clientes

🎯SELECT: Elegir Columnas

No siempre queremos * (todas las columnas)

SELECT nombre, email FROM cliente;

Solo muestra las columnas nombre y email

❌ SELECT *

Trae todos los datos (puede ser lento)

✅ SELECT columnas

Solo lo que necesitas (más rápido)

🔍WHERE: Filtrar Datos

Seleccionar solo las filas que cumplan una condición

SELECT nombre, email 
FROM cliente 
WHERE activo = true;

Solo muestra los clientes que están activos

Operadores comunes:

= Igual
!= o <> Diferente
> Mayor que
< Menor que
>= Mayor o igual
<= Menor o igual

📊ORDER BY: Ordenar Resultados

SELECT titulo, año_lanzamiento 
FROM pelicula 
ORDER BY año_lanzamiento DESC;
  • ORDER BY año_lanzamiento = Ordena por año
  • ASC = Ascendente (por defecto) ⬆️
  • DESC = Descendente ⬇️

Resultado: Películas ordenadas de más reciente a más antigua

🎚️LIMIT: Limitar Resultados

Mostrar solo los primeros N resultados

SELECT titulo 
FROM pelicula 
ORDER BY año_lanzamiento DESC 
LIMIT 5;

Solo muestra las 5 películas más recientes

💡 Tip: LIMIT es muy útil para probar consultas en tablas grandes

🔗AND, OR, NOT

Combinar múltiples condiciones

-- AND: Ambas condiciones deben cumplirse
SELECT titulo 
FROM pelicula 
WHERE año_lanzamiento > 2010 AND clasificacion = 'PG-13';
-- OR: Al menos una condición debe cumplirse
SELECT nombre 
FROM cliente 
WHERE email LIKE '%gmail.com' OR email LIKE '%hotmail.com';

🔎LIKE: Búsqueda de Patrones

LIKE permite buscar texto que coincida con un patrón

Comodines:

  • % = Cualquier cantidad de caracteres (incluso cero)
  • _ = Exactamente un carácter
LIKE 'A%'

Empieza con A

LIKE '%A'

Termina con A

LIKE '%A%'

Contiene A

LIKE 'A_'

A + 1 carácter

📦GROUP BY: Agrupar Datos

GROUP BY agrupa filas que tienen el mismo valor en una columna específica

Permite aplicar funciones de agregación a cada grupo

¿Cómo funciona?

  1. SQL agrupa todas las filas que tienen el mismo valor en la columna especificada
  2. Luego aplica la función de agregación (COUNT, SUM, AVG, etc.) a cada grupo
  3. Devuelve un resultado por grupo
SELECT categoria_id, COUNT(*) AS total 
FROM pelicula 
GROUP BY categoria_id;

Interpretación paso a paso:

  • 1️⃣ FROM pelicula → Toma todas las películas
  • 2️⃣ GROUP BY categoria_id → Las agrupa por categoría
  • 3️⃣ COUNT(*) → Cuenta cuántas hay en cada grupo
  • 4️⃣ AS total → Le da nombre a esa columna

Resultado: Cuántas películas hay en cada categoría

categoria_id total
15
23
36

En la categoría 1 hay 5 películas, en la 2 hay 3, y en la 3 hay 6

💡 Regla importante: Si usas GROUP BY, todas las columnas en el SELECT que NO sean funciones de agregación DEBEN estar en el GROUP BY
