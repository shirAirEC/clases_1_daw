JOINs básicos
EJ-12 Películas de terror

Muestra todas las películas de la categoría Terror.

SELECT p.titulo
FROM pelicula p
JOIN categoria c ON p.categoria_id = c.categoria_id
WHERE c.nombre = 'Terror';
EJ-20 Películas con categoría

Muestra el título de cada película junto con su categoría.

SELECT p.titulo, c.nombre AS categoria
FROM pelicula p
JOIN categoria c ON p.categoria_id = c.categoria_id
ORDER BY c.nombre, p.titulo;
EJ-21 Alquileres con clientes

Muestra todos los alquileres con el nombre del cliente.

SELECT a.alquiler_id, c.nombre, c.apellido, a.fecha_alquiler, a.precio_pagado
FROM alquiler a
JOIN cliente c ON a.cliente_id = c.cliente_id
ORDER BY a.fecha_alquiler DESC;
JOINs múltiples y LEFT JOIN
EJ-22 Actores y sus películas

Lista todos los actores con las películas en las que han participado.

SELECT a.nombre, a.apellido, p.titulo
FROM actor a
JOIN pelicula_actor pa ON a.actor_id = pa.actor_id
JOIN pelicula p ON pa.pelicula_id = p.pelicula_id
ORDER BY a.apellido, p.titulo;
EJ-23 Películas nunca alquiladas

Encuentra las películas que nunca han sido alquiladas.

SELECT p.titulo
FROM pelicula p
LEFT JOIN alquiler a ON p.pelicula_id = a.pelicula_id
WHERE a.alquiler_id IS NULL
ORDER BY p.titulo;
Consultas avanzadas con GROUP BY y JOINs
EJ-24 Top 5 películas más populares

Muestra las 5 películas más alquiladas con su número de alquileres.

SELECT p.titulo, COUNT(a.alquiler_id) AS veces_alquilada
FROM pelicula p
JOIN alquiler a ON p.pelicula_id = a.pelicula_id
GROUP BY p.pelicula_id, p.titulo
ORDER BY veces_alquilada DESC
LIMIT 5;
EJ-25 Ingresos por categoría

Calcula los ingresos totales generados por cada categoría de películas.

SELECT c.nombre AS categoria, SUM(a.precio_pagado) AS ingresos_totales
FROM categoria c
JOIN pelicula p ON c.categoria_id = p.categoria_id
JOIN alquiler a ON p.pelicula_id = a.pelicula_id
GROUP BY c.categoria_id, c.nombre
ORDER BY ingresos_totales DESC;
EJ-26 Actores más prolíficos

Muestra los 5 actores que han participado en más películas.

SELECT a.nombre, a.apellido, COUNT(pa.pelicula_id) AS total_peliculas
FROM actor a
JOIN pelicula_actor pa ON a.actor_id = pa.actor_id
GROUP BY a.actor_id, a.nombre, a.apellido
ORDER BY total_peliculas DESC
LIMIT 5;
Subconsultas
EJ-27 Películas por encima del promedio

Muestra las películas cuya duración es mayor que el promedio.

SELECT titulo, duracion
FROM pelicula
WHERE duracion > (SELECT AVG(duracion) FROM pelicula)
ORDER BY duracion DESC;
EJ-28 Clientes sin alquileres recientes

Encuentra clientes que no han alquilado nada en 2024.

SELECT nombre, apellido, email
FROM cliente
WHERE cliente_id NOT IN (
  SELECT DISTINCT cliente_id
  FROM alquiler
  WHERE EXTRACT(YEAR FROM fecha_alquiler) = 2024
)
ORDER BY apellido;
EJ-29 Ranking de categorías

Crea un ranking de categorías por número de alquileres totales.

SELECT c.nombre AS categoria, COUNT(a.alquiler_id) AS total_alquileres
FROM categoria c
JOIN pelicula p ON c.categoria_id = p.categoria_id
JOIN alquiler a ON p.pelicula_id = a.pelicula_id
GROUP BY c.categoria_id, c.nombre
ORDER BY total_alquileres DESC;

EJ-30 Análisis completo del videoclub

Crea un resumen con: total películas, actores, clientes activos, alquileres pendientes e ingresos totales.

SELECT
  (SELECT COUNT(*) FROM pelicula)                              AS total_peliculas,
  (SELECT COUNT(*) FROM actor)                                AS total_actores,
  (SELECT COUNT(*) FROM cliente WHERE activo = true)          AS clientes_activos,
  (SELECT COUNT(*) FROM alquiler WHERE fecha_devolucion IS NULL) AS alquileres_pendientes,
  (SELECT SUM(precio_pagado) FROM alquiler)                    AS ingresos_totales;
