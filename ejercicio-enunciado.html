Ejercicio HTML: TechSummit 2026 Lenguajes de Marcas y Sistemas de Gestión de Información — 1.º DAW

Entrega: techsummit.html

Instrucciones generales

  • Crea un único archivo llamado techsummit.html.
  • Todo el código debe ser HTML5 válido. Compruébalo con el validador del W3C.
  • No se permite usar CSS de ningún tipo (ni <style>, ni atributo style, ni archivos externos).
  • Usa etiquetas semánticas de HTML5 siempre que sea posible.
  • Los textos de contenido son libres (invéntalos) salvo los indicados literalmente entre comillas.
  • Cuida la indentación (2 o 4 espacios, consistente en todo el archivo).
  • Incluye un comentario HTML al inicio de cada parte: <!-- PARTE N -->.

Parte 1 — Estructura base del documento

Crea la estructura base del archivo HTML con los siguientes requisitos:

  1. Declaración <!DOCTYPE html>.
  2. Elemento <html> con atributo lang="es".
  3. Dentro de <head> incluye:
    • Codificación UTF-8.
    • Meta viewport para diseño responsive.
    • Meta description con una descripción del evento (mínimo 50 caracteres).
    • Meta author con tu nombre completo.
    • Meta keywords con al menos 5 palabras clave separadas por comas.
    • Título de la página: "TechSummit 2026 — Conferencia de Tecnología".
    • Un favicon apuntando a: https://em-content.zobj.net/source/apple/391/rocket_1f680.png
<!-- Estructura mínima esperada -->
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="...">
  <!-- Resto de metas... -->
  <title>...</title>
  <link rel="icon" ...>
</head>
<body>
  <!-- Aquí todo el contenido -->
</body>
</html>

Parte 2 — Cabecera y navegación

  1. Crea un <header> con:
    • Un <h1> con el texto "TechSummit 2026".
    • Un párrafo con el lema: "Donde la innovación se encuentra con el futuro".
  2. Crea un <nav> con una lista no ordenada que contenga enlaces internos (anclas con #) a las siguientes secciones:
    • Sobre el evento
    • Ponentes
    • Programa
    • Ubicación
    • Patrocinadores
    • Inscripción
    • FAQ
Los enlaces internos usan href="#id-seccion" y cada sección destino debe tener el atributo id correspondiente.

Parte 3 — Sección "Sobre el evento"

Dentro de un <main>, crea un <section> con el id correspondiente. Debe contener:

  1. Un <h2> con el título de la sección.
  2. Dos párrafos describiendo el evento (mínimo 3 líneas cada uno). En alguno usa <strong>, <em> y <mark>.
  3. Una lista de definición (<dl>, <dt>, <dd>) con estos datos:
    • Fecha: 15–17 de octubre de 2026
    • Lugar: Palacio de Congresos de Madrid
    • Aforo: 2.000 asistentes
    • Idiomas: Español e Inglés (traducción simultánea)
  4. Una imagen representativa:
    • URL: https://picsum.photos/800/400
    • Atributo alt descriptivo.
    • Atributos width="800" y height="400".
    • Envuelta en <figure> con un <figcaption>.
<!-- Ejemplo de lista de definición -->
<dl>
  <dt>Fecha</dt>
  <dd>15–17 de octubre de 2026</dd>
  <!-- Resto de términos... -->
</dl>

Parte 4 — Ponentes destacados

Crea una sección con al menos 3 ponentes. Cada ponente dentro de un <article>:

  1. Una imagen del ponente (usa https://i.pravatar.cc/150?img=N, cambiando N).
  2. Nombre en <h3>.
  3. Cargo y empresa usando <strong> y <em>.
  4. Biografía breve (2–3 frases).
  5. Un enlace ficticio a LinkedIn con target="_blank" y rel="noopener noreferrer".
target="_blank" abre en pestaña nueva. rel="noopener noreferrer" se usa por seguridad al abrir enlaces externos.

Parte 5 — Programa: tabla compleja

Crea una tabla compleja con el programa de un día de conferencia:

  1. Un <caption> con: "Programa — Día 1 (15 de octubre)".
  2. Usa <thead>, <tbody> y <tfoot>.
  3. Columnas: Hora | Sala A | Sala B | Sala C.
  4. Al menos 6 filas de actividades en <tbody>.
  5. Al menos 2 celdas con colspan (ej: inauguración y descanso que ocupan las 3 salas).
  6. Al menos 1 celda con rowspan (ej: un taller de 2 horas que ocupa 2 franjas).
  7. <tfoot> con colspan="4": "Todos los horarios en hora peninsular (CET)".
  8. <th> con scope="col" en cabeceras de columna y scope="row" en cabeceras de fila (horas).

Ejemplo orientativo

<table border="1">
  <caption>Programa — Día 1</caption>
  <thead>
    <tr>
      <th scope="col">Hora</th>
      <th scope="col">Sala A</th>
      <th scope="col">Sala B</th>
      <th scope="col">Sala C</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">09:00</th>
      <td colspan="3">Inauguración</td>
    </tr>
    <tr>
      <th scope="row">09:30</th>
      <td>Charla IA</td>
      <td>Cloud</td>
      <td rowspan="2">Taller Git (2h)</td>
    </tr>
    <!-- Más filas... -->
  </tbody>
</table>
Esta es la parte más exigente. Asegúrate de que los colspan y rowspan cuadran con el número de columnas.

Parte 6 — Ubicación y multimedia

  1. Crea una sección con id correspondiente y <h2>.
  2. Dirección completa usando <address>.
  3. Incrusta un mapa de Google Maps con <iframe>:
    • width="600", height="400".
    • loading="lazy".
    • title descriptivo (accesibilidad).
    • Para obtener el src: busca el lugar en Google Maps → Compartir → Incorporar mapa → copia la URL.
  4. Incrusta un vídeo con <video>:
    • Atributos controls, width="640", preload="metadata".
    • Al menos dos <source> (video/mp4 y video/webm). Las URLs pueden ser ficticias.
    • Texto alternativo entre las etiquetas para navegadores incompatibles.
    • Un <track> de subtítulos: kind="subtitles", srclang="es", label="Español".

Parte 7 — Patrocinadores

  1. Usa <aside> como contenedor (es contenido complementario).
  2. Un <h2>: "Nuestros patrocinadores".
  3. Tres niveles de patrocinio con <h3>:
    • Platino (1 patrocinador)
    • Oro (2 patrocinadores)
    • Plata (3 patrocinadores)
  4. Cada patrocinador: imagen dentro de un enlace (<a> que contiene <img>). El enlace va a la web ficticia de la empresa.
  5. Usa https://placehold.co/200x80?text=NombreEmpresa como URL de imagen.
  6. Todas las imágenes deben tener alt con el nombre de la empresa.

Parte 8 — Formulario de inscripción

Crea un formulario con <form action="#" method="POST">. Esta es la parte más extensa del ejercicio.

8.1 — Datos personales (primer <fieldset> con <legend>)

  • Nombre completo: input type="text", required, placeholder, minlength="3", maxlength="100".
  • Email: input type="email", required, placeholder.
  • Teléfono: input type="tel", pattern para 9 dígitos.
  • Fecha nacimiento: input type="date", con min y max razonables.
  • Web personal: input type="url", opcional.
Todos los campos deben tener un <label> asociado mediante for + id.

8.2 — Datos profesionales (segundo <fieldset>)

  • Empresa: input type="text".
  • Cargo: input con <datalist> que sugiera al menos 5 opciones (Developer, Designer, Manager, CTO, Student).
  • Años experiencia: input type="number", min="0", max="50".
  • Nivel tecnológico: input type="range", min="1", max="10", step="1". Indica los extremos con texto (1 = Principiante, 10 = Experto).
  • Tecnologías: <select multiple> con al menos 8 opciones agrupadas en 2 <optgroup> (Frontend: HTML, CSS, JavaScript, React / Backend: Java, Python, Node.js, PHP).

8.3 — Preferencias de asistencia (tercer <fieldset>)

  • Tipo de entrada (radio buttons, required): Estándar (50€), Premium (120€), VIP (250€). Mismo name.
  • Talleres (checkboxes): al menos 4 opciones.
  • Días de asistencia: <select> con: Solo día 1, Solo día 2, Solo día 3, Los 3 días.
  • ¿Cómo nos conociste?: <select> con: Redes sociales, Búsqueda web, Recomendación, Otro.
  • Comentarios: <textarea>, rows="5", cols="50", con placeholder.
  • Aceptar términos: input type="checkbox", required. El <label> incluye un enlace con texto "términos y condiciones".

8.4 — Subida y envío (cuarto <fieldset>)

  • Foto de perfil: input type="file", accept="image/*".
  • Contraseña: input type="password", minlength="8", required.
  • Campo oculto: input type="hidden", name="formulario_version", value="1.0".
  • Botón envío: <button type="submit">Completar inscripción</button>.
  • Botón reset: <button type="reset">Limpiar formulario</button>.

Parte 9 — Preguntas frecuentes

  1. Crea una sección FAQ con su id y <h2>.
  2. Al menos 5 preguntas usando <details> y <summary>.
  3. La primera pregunta debe estar abierta por defecto (atributo open).
  4. Las respuestas: al menos un párrafo cada una. Alguna debe incluir una lista ordenada dentro.
  5. Preguntas sugeridas (puedes inventar otras):
    • ¿Hay aparcamiento disponible?
    • ¿Se puede pagar en efectivo?
    • ¿Hay código de vestimenta?
    • ¿Se graban las ponencias?
    • ¿Cómo puedo cancelar mi entrada?
<!-- Ejemplo de details/summary -->
<details open>
  <summary>¿Pregunta aquí?</summary>
  <p>Respuesta aquí...</p>
</details>

Parte 10 — Pie de página

  1. Crea un <footer> con:
  2. Un párrafo con <small> que contenga el símbolo copyright (&copy;) y "2026 TechSummit. Todos los derechos reservados."
  3. Enlaces a:
    • Política de privacidad (href="#")
    • Aviso legal (href="#")

Checklist de etiquetas HTML

Tu archivo debería utilizar, como mínimo, todas estas etiquetas:

Estructura html, head, body, header, nav, main, section, article, aside, footer
Texto h1–h3, p, strong, em, mark, small, code
Listas ul, ol, li, dl, dt, dd
Tablas table, caption, thead, tbody, tfoot, tr, th, td
Formularios form, fieldset, legend, label, input, select, optgroup, option, textarea, datalist, button, output
Multimedia img, figure, figcaption, video, source, track, iframe
Enlaces a (href, target, rel), mailto:, tel:
Interactivo details, summary
Meta meta (charset, viewport, description, author, keywords), title, link
Otros address, hr, entidades (&copy; &lt; &euro;)
